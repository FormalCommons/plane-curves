## Conventions

- **Points and charts.** `𝔸ⁿ` is `Fin n → k`, `ℙⁿ` is
  `ℙ k (Fin (n + 1) → k)`. Every statement takes the chart `i : Fin (n + 1)`
  as a parameter, as Tau Ceti's `Ideal.homogenization J i`,
  `TauCeti.dehomogenize i` and `Projectivization.affineChart i` do; Fulton's
  `φ = φ_{n+1}` and `H_∞ = V(X_{n+1})` are the case `i = Fin.last n`. P16
  needs every chart ("state (b) for every chart", atlas, milestone
  *Affine charts preserve function fields and local rings*), and the
  generality costs nothing.
- **The embedding** `φ_i : 𝔸ⁿ → ℙⁿ` is `(affineChart i).symm`
  (Tau Ceti, `TauCeti/LinearAlgebra/Projectivization/AffineChart.lean`;
  `affineChart_symm_apply : (affineChart i).symm z = mk K (Fin.insertNth i 1 z) _`),
  its image is `affineOpen i` (`affineChart_source`, `affineChart_target`),
  and the hyperplane at infinity `H_∞` is `(affineOpen i)ᶜ`, which is
  `Set.range (insertZero i)` by P1's `range_insertZero`. Statements use
  `(affineOpen i)ᶜ`; no new name for `H_∞`.
- **Algebraic sets.** There is no predicate for them: an affine set `V` is
  algebraic when `MvPolynomial.zeroLocus k (MvPolynomial.vanishingIdeal k V) = V`
  (Mathlib, `RingTheory/Nullstellensatz.lean`, with `K = k`), a projective
  set `W` when `ProjectiveSpace.zeroLocus (ProjectiveSpace.vanishingIdeal W) = W`
  (P4). Hypotheses are written this way.
- **Varieties** follow `DESIGN.md` (no Zariski topology, irreducibility
  stated algebraically, Mathlib's conventions): an affine variety is an
  algebraic `V` with `(vanishingIdeal k V).IsPrime` (so `V ≠ ∅`), a
  projective variety an algebraic `W` with
  `(ProjectiveSpace.vanishingIdeal W).toIdeal.IsPrime` (so `W ≠ ∅`).
  An irreducible decomposition is a finite family of varieties whose union
  is the set, with no member contained in another.
- Every file that mentions `HomogeneousIdeal` of a polynomial ring writes
  `attribute [local instance] MvPolynomial.gradedAlgebra`.

## Generality

The atlas states the milestone for algebraically closed `k`, and says that
(7) and (f) need the Nullstellensatz. The proofs below need less, and the
statements take the weakest hypothesis that the proof uses:

| Statement | Field |
|---|---|
| definitions, (b), (1), (2), (3), (4), (5), (7) without `V_* ≠ 𝔸ⁿ`, (f) | any field |
| (6), `V_* ≠ 𝔸ⁿ` in (7) | `[Infinite k]` |
| (d) `V(F)* = V(F*)` | `[IsAlgClosed k]` |

The key to the general case is that `I(V*) = I(V)*` for **every** set `V`
over any field (piece 2), and that for a projective variety `W ⊄ H_∞`,
`(W_*)* = W` follows from primality of `I(W)` alone: `W ⊆ (W_*)* ∪ (W ∩ H_∞)`
and `I(W)` is prime (piece 4). Over a finite field the statements are true
but degenerate (every set is algebraic). (d) fails over `ℝ`: for
`F = 1 + X²Y²`, `V(F) = ∅` but `V(F*) = V(Z⁴ + X²Y²) ∋ [1:0:0]`; so
`[IsAlgClosed k]` stays there. None of this is an error of the atlas, so
`ERRATA.md` gets no entry.

## Definitions

In `ProjectiveClosure.lean`, namespace `PlaneCurves.ProjectiveSpace`,
`variable {k : Type*} [Field k] {n : ℕ}`:

```lean
/-- The projective closure `V*` of a set `V ⊆ 𝔸ⁿ` with respect to the chart `i`:
the zero locus in `ℙⁿ` of the homogenization of the ideal of `V`. -/
def projectiveClosure (i : Fin (n + 1)) (V : Set (Fin n → k)) :
    Set (ℙ k (Fin (n + 1) → k)) :=
  zeroLocus ((MvPolynomial.vanishingIdeal k V).homogenization i : Set _)

/-- The affine part `V_*` of a set `V ⊆ ℙⁿ` with respect to the chart `i`:
the zero locus in `𝔸ⁿ` of the dehomogenization of the ideal of `V`. -/
def affinePart (i : Fin (n + 1)) (V : Set (ℙ k (Fin (n + 1) → k))) :
    Set (Fin n → k) :=
  MvPolynomial.zeroLocus k ((vanishingIdeal V).toIdeal.map (TauCeti.dehomogenize i))
```

These are Fulton's definitions word for word (`V* = V(I(V)*)`,
`V_* = V(I(V)_*)`); the atlas's formalization note identifies Tau Ceti's
`Ideal.homogenization` with Fulton's `J*` (P13 proves it,
`Ideal.homogenization_eq_span_homogenize`) and Fulton's `I_*` with
`Ideal.map (TauCeti.dehomogenize i) I`. The exact form of the argument of
`zeroLocus` (a set or an ideal) follows P4's signature. Each definition comes
with `projectiveClosure_def` and `affinePart_def`, proved by `(rfl)`.

### Piece 2: definitions, the chart and Proposition 3 (1), (2), (5) (about 250 lines)

In `ProjectiveClosure.lean`, over any field. `V ⊆ 𝔸ⁿ`, `W ⊆ ℙⁿ` arbitrary
sets unless stated.

- `projectiveClosure_def`, `affinePart_def`.
- **(b), `V_* = φ⁻¹(V)`.** `affinePart_eq_preimage : affinePart i W = (affineChart i).symm ⁻¹' zeroLocus (vanishingIdeal W)`,
  and `mem_affinePart_iff (hW : zeroLocus (vanishingIdeal W) = W) : a ∈ affinePart i W ↔ (affineChart i).symm a ∈ W`.
  Proof: `I(W)` is homogeneous, so a point of `ℙⁿ` is in `V(I(W))` iff the
  forms of `I(W)` vanish at one representative (P4's `mk_mem_zeroLocus_iff`),
  and `F_*(a) = F(insertNth i 1 a)` (Tau Ceti's `TauCeti.eval_dehomogenize`).
  The atlas asks for this first, since everything about `V_*` goes through
  it. Corollaries: `affinePart_mono`, `affinePart_union` (for algebraic
  `W`, `W'`; P4's union lemma), `affinePart_univ`, `affinePart_empty`.
- `image_subset_projectiveClosure : (affineChart i).symm '' V ⊆ projectiveClosure i V`
  (`φ(V) ⊆ V*`; Tau Ceti's `Ideal.dehomogenize_mem_of_mem_homogenization`).
- **The key lemma.** `vanishingIdeal_projectiveClosure : vanishingIdeal (projectiveClosure i V) = (vanishingIdeal k V).homogenization i`,
  for every set `V`. `⊇` is P4's Galois connection; `⊆`: a form `F`
  vanishing on `V*` vanishes on `φ(V)`, so `F_* ∈ I(V)`, so `F ∈ I(V)*`
  (`mem_homogenization_iff_of_isHomogeneous`), and `I(V*)` is homogeneous.
- **(5)** `projectiveClosure_subset_iff (hW : zeroLocus (vanishingIdeal W) = W) : projectiveClosure i V ⊆ W ↔ (affineChart i).symm '' V ⊆ W`:
  `V*` is the smallest algebraic set containing `φ(V)`. Proof as the book's
  (atlas note 8: for the forms of `I(W)`), through Tau Ceti's
  `Ideal.le_homogenization_iff` applied to `I(W)`. Also
  `projectiveClosure_zeroLocus_vanishingIdeal` (`V*` is algebraic: it is a
  zero locus, by P4).
- **(2)** `projectiveClosure_mono : Monotone (projectiveClosure (k := k) i)`
  (piece 1's `homogenization_mono`), and `affinePart_mono` above.
- **(1)** `projectiveClosure_inter_affineOpen (hV : zeroLocus k (vanishingIdeal k V) = V) : projectiveClosure i V ∩ affineOpen i = (affineChart i).symm '' V`
  and `affinePart_projectiveClosure (hV) : affinePart i (projectiveClosure i V) = V`.
  Proof: by `affinePart_eq_preimage`, `a ∈ (V*)_*` iff every form `G` with
  `G_* ∈ I(V)` has `G_*(a) = 0`; every `f ∈ I(V)` is such a `G_*`
  (Tau Ceti's `Ideal.map_dehomogenize_homogenization`); so `(V*)_* = V(I(V)) = V`.
- Consequences used later: `projectiveClosure_subset_projectiveClosure_iff`
  (`V* ⊆ V'* ↔ V ⊆ V'` for algebraic `V`), `projectiveClosure_injOn` on
  algebraic sets, `projectiveClosure_union` (`(V ∪ V')* = V* ∪ V'*` for all
  sets: `I(V ∪ V') = I(V) ⊓ I(V')`, piece 1's `homogenization_inf`, and P4's
  `V(I ⊓ J) = V(I) ∪ V(J)`), `projectiveClosure_biUnion` for a `Finset`
  of indices, `projectiveClosure_empty` (`homogenization_top`), and
  `projectiveClosure_univ [Infinite k] : projectiveClosure i univ = univ`
  (`I(𝔸ⁿ) = ⊥` by Mathlib's `MvPolynomial.funext`, then
  `homogenization_bot`). Piece 4 also uses `I(ℙⁿ) = ⊥` over infinite `k`;
  that is P4's `ProjectiveSpace.vanishingIdeal_univ [Infinite k]`, not
  reproved here.

### Piece 3: closures of varieties, (3), (4), (6) and (d) (about 200 lines)

- **(3)** `isPrime_vanishingIdeal_projectiveClosure (h : (vanishingIdeal k V).IsPrime) : (vanishingIdeal (projectiveClosure i V)).toIdeal.IsPrime`:
  by the key lemma and P13's `Ideal.IsPrime.homogenization`. With
  `projectiveClosure_nonempty` (`V ≠ ∅ → V* ≠ ∅`, from
  `image_subset_projectiveClosure`), the closure of an affine variety is a
  projective variety.
- **(4)** `projectiveClosure_biUnion` (piece 2) with (3) and
  `projectiveClosure_subset_projectiveClosure_iff`: for a finite family
  `Vⱼ` of affine varieties with `V = ⋃ Vⱼ` and `¬ Vⱼ ⊆ Vₗ` for `j ≠ l`, the
  `Vⱼ*` are projective varieties with `V* = ⋃ Vⱼ*` and `¬ Vⱼ* ⊆ Vₗ*`. One
  theorem, `projectiveClosure_irreducibleDecomposition` (name to be
  adapted to the form P6 gives decompositions, if P6 gives one).
- **(6)** for an affine variety `V`, `¬ projectiveClosure i V ⊆ (affineOpen i)ᶜ`
  (any field: `φ(V) ⊆ V* ∩ affineOpen i` is nonempty), and
  `compl_affineOpen_not_subset_projectiveClosure [Infinite k] (hV) (hne : V ≠ univ) (hne' : V.Nonempty) : ¬ (affineOpen i)ᶜ ⊆ projectiveClosure i V`,
  for algebraic `V` (irreducibility is not needed). `hne'` is Fulton's
  `∅ ≠ V`, and it forces `n ≥ 1`; without it the statement is false for
  `n = 0`, `V = ∅`, where `(affineOpen i)ᶜ = ∅ ⊆ V*`. Proof: `I(V) ≠ ⊥`
  (`V = V(I(V)) ≠ 𝔸ⁿ`); for `0 ≠ f ∈ I(V)` of degree `N`, `f* ∈ I(V*)`, and
  `f*` restricted to `Xᵢ = 0` is the nonzero top component of `f`
  (piece 1's `eval_insertNth_zero_homogenize`), which over infinite `k` has
  a non-root (`MvPolynomial.funext`); `N ≥ 1` since `V ≠ ∅`, so the point is
  nonzero and lies in `H_∞ \ V*`. This avoids Fulton's
  `I(H_∞) = (X_{n+1})`. Combined with (4): no component of `V*` lies in or
  contains `H_∞` when `∅ ≠ V ⊊ 𝔸ⁿ`.
- **(d)** `projectiveClosure_zeroLocus_span_singleton [IsAlgClosed k] (hF : F ≠ 0) : projectiveClosure i (zeroLocus k (span {F})) = ProjectiveSpace.zeroLocus {homogenize i F.totalDegree F}`.
  Proof: `I(V(F)) = rad (F)` (Mathlib's `MvPolynomial.vanishingIdeal_zeroLocus_eq_radical`),
  `rad(F)* ≤ rad((F)*)` (piece 1's `homogenization_radical_le`), `(F)* = (F*)`
  (P13's `Ideal.homogenization_span_singleton`), and the zero locus of an
  ideal equals that of its radical (P4's `ProjectiveSpace.zeroLocus_radical`).

### Piece 4: affine parts of projective varieties, (7) and (f) (about 250 lines)

`W` is a projective variety with `¬ W ⊆ (affineOpen i)ᶜ`.

- **(7), the main step.** `projectiveClosure_affinePart : projectiveClosure i (affinePart i W) = W`.
  Proof (any field): `⊆` is (5), since `φ(W_*) ⊆ W` by
  `mem_affinePart_iff`; `⊇`: `W ⊆ (W_*)* ∪ (W ∩ V(Xᵢ))`, both algebraic, so
  `I((W_*)*) ⊓ I(W ∩ V(Xᵢ)) ≤ I(W)` (P4), and `I(W)` prime gives
  `W ⊆ (W_*)*` or `W ⊆ V(Xᵢ) = (affineOpen i)ᶜ`; the second is excluded.
  This uses only P4 and primality, not P6's components or the
  Nullstellensatz.
- `vanishingIdeal_affinePart : vanishingIdeal k (affinePart i W) = (vanishingIdeal W).toIdeal.map (TauCeti.dehomogenize i)`
  (`I(W_*) = I(W)_*`, which P16 uses): apply the key lemma to `W_*`, then
  `map_dehomogenize_homogenization`. Then
  `isPrime_vanishingIdeal_affinePart` (piece 1's `IsPrime.of_homogenization`),
  so `W_*` is an affine variety.
- `affinePart_ne_univ [Infinite k] (h : ¬ (affineOpen i)ᶜ ⊆ W) : affinePart i W ≠ univ`
  (if `W_* = 𝔸ⁿ` then `W = (𝔸ⁿ)* = ℙⁿ` by `projectiveClosure_univ`).
- **(7) for a decomposition.** For a finite family `Wⱼ` of projective
  varieties, none contained in and none containing `(affineOpen i)ᶜ`, with
  union `W`: `affinePart i W ≠ univ` (`[Infinite k]`) and
  `projectiveClosure i (affinePart i W) = W`, by `affinePart_union` and
  `projectiveClosure_biUnion` (the reduction the atlas's note 8 asks for).
  The step `affinePart i W ≠ univ` also needs `ℙⁿ` irreducible over
  infinite `k`: if `W_* = 𝔸ⁿ`, then by (7) for each `Wⱼ`,
  `ℙⁿ = (𝔸ⁿ)* = ⋃ ((Wⱼ)_*)* = ⋃ Wⱼ`. Over infinite `k`,
  `I(ℙⁿ) = ⊥` (P4's `ProjectiveSpace.vanishingIdeal_univ [Infinite k]`) is
  prime, so by P4, as in (7) and by induction on
  the family, `ℙⁿ ⊆ Wⱼ` for some `j`, contradicting `¬ (affineOpen i)ᶜ ⊆ Wⱼ`.
- **(f)** `projectiveClosureEquiv i : {V : Set (Fin n → k) // zeroLocus k (vanishingIdeal k V) = V ∧ (vanishingIdeal k V).IsPrime} ≃ {W : Set (ℙ k (Fin (n + 1) → k)) // zeroLocus (vanishingIdeal W) = W ∧ (vanishingIdeal W).toIdeal.IsPrime ∧ ¬ W ⊆ (affineOpen i)ᶜ}`,
  with `toFun = projectiveClosure i`, `invFun = affinePart i`, and `@[simp]`
  lemmas `projectiveClosureEquiv_apply`, `projectiveClosureEquiv_symm_apply`.
  Inverse laws: `affinePart_projectiveClosure` and
  `projectiveClosure_affinePart`. Any field.
