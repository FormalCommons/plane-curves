## Approach

The atlas states the milestone for a nonsingular cubic `C`, and part (d)
(Problem 5.35) for the simple points `C°` of an irreducible cubic. The
proofs of (a)–(c) use only that the points involved are simple and that `C`
is irreducible, so the part does everything once, for the simple points of an
irreducible cubic, in every characteristic and for every base point `O`, as
`DESIGN.md` asks ("proved as Fulton does, for any base point and any
characteristic"). A nonsingular cubic is irreducible (`IsNonsingular.irreducible`,
Q2) and all its points are simple (`isNonsingular_iff_forall_isSimplePoint`,
Q2), so the nonsingular case is the special case `C° = C`.

Throughout, `k` is a field with `[IsAlgClosed k]` (Bézout's theorem needs
it), `F : MvPolynomial (Fin 3) k` is an irreducible form of degree 3, and
points are `ℙ k (Fin 3 → k)`. A *line* is a form `L` with
`L.IsHomogeneous 1` and `L ≠ 0`. Fulton's `L • C = P + Q + R` is
`intersectionCycle L F = single P 1 + single Q 1 + single R 1` in
`ℙ k (Fin 3 → k) →₀ ℕ` (N1).

- **φ (a).** For simple points `P, Q` of `F`, `chordLine F P Q` is the line
  through `P` and `Q` if `P ≠ Q`, and the tangent at `P` if `P = Q`. It is
  not a component of `F` (degree), so by Bézout its intersection cycle with
  `F` has degree 3. It contains `P + Q`: each point once if `P ≠ Q`, and `P`
  at least twice if `P = Q` (tangency, Q7). The rest is one point,
  `thirdPoint F P Q`. That point is simple: a multiple point `R` would have
  `I(R, L ∩ F) ≥ 2` (property (5)), which is too much unless `R` is `P` or
  `Q`, which are simple (atlas, proof route (d)).
- **Uniqueness.** Any line `L` with `intersectionCycle L F = P + Q + R`
  is a nonzero multiple of `chordLine F P Q`, and then `R = thirdPoint F P Q`.
  This gives `thirdPoint_comm` and `thirdPoint_thirdPoint`
  (`φ(P, φ(P, Q)) = Q`) at once.
- **⊕ (b).** `P ⊕ Q = φ(O, φ(P, Q))`. The identity, commutativity and
  inverses (`-P = φ(P, φ(O, O))`) follow from the two identities of φ (Fulton
  leaves them to the reader, atlas note 10). Associativity is the book's
  argument: with the six lines `L₁, M₁, L₂, M₂, L₃, M₃` of the atlas's proof
  route, the eight-points theorem (**5-ninth**, N3) applied to
  `C' = L₁L₂L₃` and `C'' = M₁M₂M₃` gives `T' = T''`. Coincidences need no
  separate treatment, because the theorem is stated with multiplicities.
  `C'`, `C''` are not multiples of `F`, since `F` is irreducible of degree 3
  and each `Lᵢ` has degree 1.
- **Collinearity criterion (b).** In the group, `φ(P, Q) = φ(O, O) - P - Q`.
  Hence `L • C = P + Q + R` for a line `L` iff `P + Q + R = φ(O, O)`.
- **Change of base point (c).** From that formula, `P ↦ φ(φ(O, O'), P)` is
  `P ↦ O' - P` in `(C°, O)`, and `⊕'` is `P + Q - O'`. So the map is an
  additive isomorphism `(C°, O) ≃+ (C°, O')` by a computation in the group,
  with no more geometry.

The group is a definition that depends on `O`. Its carrier is a structure
`CubicGroup F O` that carries `O` as a parameter, with an `AddCommGroup`
instance. There is no instance on the set of simple points itself, as the
atlas asks ("a type synonym carrying `O` rather than a global instance").
There is no second group law on Weierstrass curves: part N7 compares
`CubicGroup W.polynomial [0:1:0]` with Mathlib's `W.Point` by an `AddEquiv`.

## Definitions and API

### `Cubic/Chord.lean`

- **`chordLine (F) (P Q : ℙ k (Fin 3 → k)) : MvPolynomial (Fin 3) k`**
  (`open Classical`): if `P ≠ Q`, the linear form `∑ i, C (a i) * X i` with
  `a = (Projectivization.cross P Q).rep`. Mathlib's `cross` is the point of
  the dual plane orthogonal to `P` and `Q`. If `P = Q`, it is
  `tangentLine F P.rep` (Q3). If P8 or P9 already gives the linear form of a
  point of the dual plane, or the line through two points, as a form, use
  that and do not add a second one. API:
  - `chordLine_comm` (`chordLine F P Q = chordLine F Q P`, from `cross_comm`);
  - `isHomogeneous_chordLine` (degree 1);
  - `chordLine_ne_zero` (for `P ≠ Q`, or `P` simple);
  - `eval_chordLine_left`, `eval_chordLine_right` (the form vanishes at
    representatives of `P` and `Q`, `P = Q` simple in the tangent case);
  - `chordLine_eq_smul_of_eval_eq_zero` (`P ≠ Q`: a line vanishing at `P` and
    `Q` is `c • chordLine F P Q`, `c ≠ 0`: the point of the dual plane it
    defines is orthogonal to `P` and `Q`, so it is `cross P Q` by
    `Configuration.ofField.eq_or_eq_of_orthogonal` with
    `cross_orthogonal_left` and `cross_orthogonal_right`);
  - `isRelPrime_chordLine` (`IsRelPrime (chordLine F P Q) F` for irreducible
    `F` of degree ≥ 2: `Irreducible.isRelPrime_iff_not_dvd` with
    `MvPolynomial.totalDegree_le_of_dvd_of_isDomain`). Stated for any line
    `L`, as `isRelPrime_of_isHomogeneous_one`, if no earlier part has it.
- **`thirdPoint (F) (P Q : ℙ k (Fin 3 → k)) : ℙ k (Fin 3 → k)`** (φ;
  `open Classical`): the `R` with
  `intersectionCycle (chordLine F P Q) F = single P 1 + single Q 1 + single R 1`,
  if there is one, and `P` otherwise (a junk value, never used). Give
  `thirdPoint_def`. In the API below, `hF : F.IsHomogeneous 3`,
  `hirr : Irreducible F`, and `P`, `Q` are simple points of `F`:
  - `intersectionCycle_chordLine`: the cycle equation above, with
    `R = thirdPoint F P Q`. This is the existence half of (a);
  - `eq_thirdPoint_of_intersectionCycle_eq`: if `L` is a line with
    `intersectionCycle L F = single P 1 + single Q 1 + single R 1`, then
    `R = thirdPoint F P Q`;
  - `eq_smul_chordLine_of_intersectionCycle_eq`: such an `L` is
    `c • chordLine F P Q` with `c ≠ 0`. This is the uniqueness half of (a).
    For `P = Q` it uses the tangency criterion (Q7: a line through a simple
    point `P` with `I(P, F ∩ L) ≥ 2` is the tangent);
  - `isSimplePoint_thirdPoint` (with property (5), Q7);
  - `thirdPoint_comm` (`φ(P, Q) = φ(Q, P)`);
  - `thirdPoint_thirdPoint` (`φ(P, φ(P, Q)) = Q`), and
    `thirdPoint_thirdPoint'` (`φ(φ(P, Q), Q) = P`), both by uniqueness;
  - `thirdPoint_eq_iff` (`thirdPoint F P Q = R ↔ ∃ L` a line with the cycle
    equation), the form the group law uses.

  Invariance under `c • F` (`thirdPoint_smul`, `chordLine_smul`), as
  `DESIGN.md`'s principles ask, from `intersectionCycle`'s and
  `IsSimplePoint`'s invariance.

### `Cubic/GroupLaw.lean`

- **`structure CubicGroup (F : MvPolynomial (Fin 3) k) (O : ℙ k (Fin 3 → k))`**
  with fields `point : ℙ k (Fin 3 → k)` and
  `isSimplePoint : IsSimplePoint F point`, `@[ext]`: the simple points of
  `F`, with base point `O`. `O` is only a parameter, so the group structures
  for different base points live on different types. API: `point_injective`,
  `mk_point`, an `Equiv` `CubicGroup.equivSubtype` to
  `{P // IsSimplePoint F P}`, and `CubicGroup.ofPoint` for changing `O`
  (`CubicGroup F O → CubicGroup F O'`, the identity on points).
- **`CubicGroup.chord : CubicGroup F O → CubicGroup F O → CubicGroup F O`**
  (φ on simple points, from `thirdPoint` and `isSimplePoint_thirdPoint`),
  with `point_chord`, `chord_comm`, `chord_chord`.
- **Instance** `[Fact (F.IsHomogeneous 3)] [Fact (Irreducible F)]
  [Fact (IsSimplePoint F O)] : AddCommGroup (CubicGroup F O)`, with
  `0 = ⟨O, _⟩`, `P + Q = chord ⟨O, _⟩ (chord P Q)`,
  `-P = chord P (chord 0 0)`, and `nsmul` and `zsmul` by default. `Fact`
  carries the hypotheses, as Tau Ceti and `DESIGN.md` do for
  `functionField`. API, `@[simp]` where they put terms in normal form:
  - `point_zero`, `point_add` (`(P + Q).point = thirdPoint F O (thirdPoint F P.point Q.point)`),
    `point_neg` (`(-P).point = thirdPoint F P.point (thirdPoint F O O)`);
  - `add_assoc` is the proof of `CubicGroup.add_assoc'`, a public lemma that
    states associativity in terms of `thirdPoint`:
    `φ(O, φ(φ(O, φ(P, Q)), R)) = φ(O, φ(P, φ(O, φ(Q, R))))`, for simple
    `P, Q, R, O`. It is the only use of **5-ninth**, and the longest proof of
    the part. Split it into lemmas: the two intersection cycles of
    `L₁L₂L₃` and `M₁M₂M₃` as sums of nine points (`intersectionCycle_mul`,
    N1), "not a multiple of `F`", then the application of N3;
  - `chord_eq_sub` (`chord P Q = chord 0 0 - P - Q`), the key identity for
    the rest;
  - `exists_line_iff_add_add_eq` (collinearity criterion: there is a line `L`
    with `intersectionCycle L F = single P 1 + single Q 1 + single R 1` iff
    `P + Q + R = chord 0 0`);
  - `chord_zero_zero_eq_zero_iff` (`φ(O, O) = O` iff `O` is a flex of `F`).
    This is optional, and only if Q17's `IsFlex` is in place; part N8
    otherwise.
- **`CubicGroup.changeBase (O O') : CubicGroup F O ≃+ CubicGroup F O'`**
  (needs both `Fact`s for simple points), `P ↦ φ(φ(O, O'), P)`. API:
  `point_changeBase` (the formula), `changeBase_symm`
  (`= changeBase O' O`), `changeBase_self_apply`
  (`changeBase O O P = -P`: it is not the identity, since
  `φ(φ(O, O), P) = -P`), `changeBase_apply_eq_sub` (`= ofPoint (O' - P)`,
  computed in `(C°, O)`). Prove that it is additive, and the inverse
  formula, from `chord_eq_sub` alone: in `(C°, O)` the law of `(C°, O')` is
  `P + Q - O'`.
- **Nonsingular cubics.** `CubicGroup.ofMem (hns : IsNonsingular F) (hP : P ∈ zeroLocus {F})`
  (every point of `V(F)` is a point of the group), with `IsNonsingular.irreducible`
  turning the `Fact` hypotheses of the instance into `hF : F.IsHomogeneous 3`
  and nonsingularity. `CubicGroup.equivZeroLocus : CubicGroup F O ≃ zeroLocus {F}`
  for nonsingular `F` (`ProjectiveSpace.zeroLocus`, P4).

## The milestone

One theorem in `Cubic/GroupLaw.lean` carries the milestone line. It is
stated for an irreducible cubic and its simple points, which is part (d),
and more general than (a)–(c). For a nonsingular cubic its hypotheses come
from `IsNonsingular.irreducible` and `isNonsingular_iff_forall_isSimplePoint`
(Q2), and
`CubicGroup.equivZeroLocus` identifies the carrier with `C = V(F)`. Proposed
name `CubicGroup.chordTangent_group`, statement, for `hF : F.IsHomogeneous 3`,
`hirr : Irreducible F` and a simple point `O`:

1. (a) for simple `P, Q`:
   `intersectionCycle (chordLine F P Q) F = single P 1 + single Q 1 + single (thirdPoint F P Q) 1`;
   every line `L` with `intersectionCycle L F = single P 1 + single Q 1 + single R 1`
   is a nonzero multiple of `chordLine F P Q`, and `R = thirdPoint F P Q`;
   `thirdPoint F P Q` is simple, `thirdPoint F P Q = thirdPoint F Q P`,
   `thirdPoint F P (thirdPoint F P Q) = Q`;
2. (b) in `CubicGroup F O`: `(P + Q).point = thirdPoint F O (thirdPoint F P.point Q.point)`,
   `(0 : CubicGroup F O).point = O`,
   `(-P).point = thirdPoint F P.point (thirdPoint F O O)`, and the
   collinearity criterion `exists_line_iff_add_add_eq`. The group axioms are
   the instance;
3. (c) for a second simple point `O'`, there is an
   `e : CubicGroup F O ≃+ CubicGroup F O'` with
   `(e P).point = thirdPoint F (thirdPoint F O O') P.point` (namely
   `changeBase`).

Its docstring ends with "Milestone: *Group law on a nonsingular plane
cubic*." The statement uses the atlas's hypotheses or weaker ones: an
irreducible cubic instead of a nonsingular one, and simple points. It makes
no characteristic assumption and holds for every base point, as the atlas
says. No entry in `ERRATA.md` is needed. The atlas already restricts (d) to
irreducible cubics (atlas note 9), and the gap in Proposition 3 (note 7) is
N3's to fix.

## Pieces

Four pieces, in this order, each one issue and one pull request. Each piece
needs the previous one, and all four need N3 and Q2 merged.

1. **Chord lines** (`Cubic/Chord.lean`, first half; about 200 lines).
   `chordLine` and its API up to `chordLine_eq_smul_of_eval_eq_zero` and
   `isRelPrime_chordLine`. Done when `chordLine` has the API listed above, with
   docstrings, and `lake build --wfail` passes.
2. **The third point** (`Cubic/Chord.lean`, second half; about 250 lines).
   `thirdPoint` and its API: `intersectionCycle_chordLine`,
   `eq_smul_chordLine_of_intersectionCycle_eq`,
   `eq_thirdPoint_of_intersectionCycle_eq`, `isSimplePoint_thirdPoint`,
   `thirdPoint_comm`, `thirdPoint_thirdPoint`, `thirdPoint_eq_iff`. Done
   when these are proved for an irreducible cubic and simple points.
3. **The group** (`Cubic/GroupLaw.lean`, first half; about 300 lines).
   `CubicGroup`, `CubicGroup.chord`, the associativity lemma
   `CubicGroup.add_assoc'` from **5-ninth**, and the `AddCommGroup` instance
   with `point_zero`, `point_add`, `point_neg`. Done when the instance is in
   place without `sorry`, and `#print axioms` of `CubicGroup.add_assoc'` shows
   only the standard three.
4. **Criterion, change of base point, milestone** (`Cubic/GroupLaw.lean`,
   second half; about 250 lines). `chord_eq_sub`,
   `exists_line_iff_add_add_eq`, `changeBase` with its API, `ofMem` and
   `equivZeroLocus` for nonsingular cubics, and the milestone theorem
   `CubicGroup.chordTangent_group` with its milestone line. Done when the
   milestone theorem is proved in the form above and `#print axioms` shows
   only `propext`, `Classical.choice` and `Quot.sound`.
