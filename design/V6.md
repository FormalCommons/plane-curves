## Notation

Everything about the curve is in the namespace `PlaneCurves.Projective`, with
the variables of V3 (`Place/Basic.lean`):

```lean
variable {k : Type*} [Field k] [IsAlgClosed k] {F : MvPolynomial (Fin 3) k} {d : ℕ}
  (hF : F.IsHomogeneous d) [Fact (Irreducible F)]
```

- `C` is `zeroLocus (projectivePlaneCurve.ideal hF : Set (MvPolynomial (Fin 3) k))`.
  Its points are `P : C`, and `P.1.rep` is a representative.
- `K` is `functionField hF`, `𝒪_P` is `(localSubring hF P).toSubring`
  (Q5, `Projective/CurveLocalRing.lean`), and `f / g` is
  `functionField.mk hf hg hgI` (P11, `ProjectiveSpace/FunctionField.lean`).
- The nonsingular model is the set `Place k K` with the centre map
  `center hF` (V2). So, for `U : Set C`, Fulton's `U' = f⁻¹(U)` is
  `center hF ⁻¹' U`, and `Γ(U')` is Tau Ceti's
  `holomorphyRing (center hF ⁻¹' U)`. The places over `P` are
  `placesOver hF P = center hF ⁻¹' {P}` (V3).
- For a form `G` of degree `m`, `D(G)` is `{P : C | eval P.1.rep G ≠ 0}`.
  This is a set-builder, not a definition (see [Decision 2](#2-which-neighbourhoods-u)).
- `holomorphyRing`, `Place`, `IsFunctionField` are in the namespace `TauCeti`.

## The route

This is the atlas's characteristic-free route: integral closure and Japanese
rings, not the book's route through quadratic transformations. One point
keeps the work small. The library never proves that `Γ(D(G))` *equals* the
ring `A_G` of fractions `H / Gʳ`. It only proves `A_G ⊆ Γ(D(G))`. That
equality would be the projective analogue of R1's `regularFunctionsOn_basicOpen`,
and it needs a projective Nullstellensatz. Instead, `Γ(D(G))` is caught
between two rings whose properties are known:

```
A_G  ⊆  Γ(U)  ⊆  Γ(U')  =  integral closure of A_G in K,      U = D(G).
```

1. **`A_G` is a finitely generated `k`-domain with fraction field `K`**
   (`¬ F ∣ G` and `m ≠ 0`; for `m = 0`, `G` is a nonzero constant and
   `A_G = k`). It is generated by the fractions `M / G` for the monomials
   `M` of degree `m`, since a monomial of degree `r·m` is a product of `r`
   monomials of degree `m`. Every `f / g ∈ K` with `deg f = deg g = e` is
   `(f·g^{m-1} / G^e) / (g^m / G^e)`, a quotient of two elements of `A_G`.
2. **The places of `A_G` are those centred in `D(G)`**:
   `{Q | A_G ⊆ 𝒪_Q} = center hF ⁻¹' D(G)`. If `G(center Q) ≠ 0`, then
   `A_G ⊆ 𝒪_{center Q} ⊆ 𝒪_Q`. If `G(center Q) = 0`, choose `i` with
   `Xᵢ(center Q) ≠ 0`. Then `ordForm Q G > 0` (`ordForm_pos_iff`), so
   `Xᵢᵐ / G ∈ A_G` has negative order at `Q`
   (`ordForm_eq_addValuation_mk`).
3. **Integral closure.** By 2 and Tau Ceti's
   `restrictScalars_integralClosure_eq_holomorphyRing`, the integral closure
   of `A_G` in `K` is `holomorphyRing (center hF ⁻¹' D(G)) = Γ(U')`. It is
   module-finite over `A_G`, because `A_G` is Japanese
   (`IsUniversallyJapanese.isJapanese` with the instance for the field `k`,
   then `IsJapanese.finite_integralClosure A_G K K`).
4. **The sandwich.** `A_G ⊆ Γ(U)` by 1, since `G(P) ≠ 0` for `P ∈ U`.
   `Γ(U) ⊆ Γ(U')` since `𝒪_{center Q} ⊆ 𝒪_Q` (`localSubring_center_le`).
   So `Γ(U)` is an `A_G`-submodule of a finite module over the Noetherian
   ring `A_G`. Hence it is a finite `A_G`-module and a finitely generated
   `k`-algebra. Its fraction field is `K`, since it contains `A_G`. Its
   integral closure in `K` is also `Γ(U')`, which is finite over `Γ(U)`
   because it is finite over `A_G`. That is (2).
5. **(1).** `U'ᶜ = center hF ⁻¹' (C ∖ D(G))`. It is finite, since
   `C ∖ D(G) = V(F, G)` is finite (`finite_zeroLocus_pair_of_isRelPrime`)
   and so are the fibres (`placesOver_finite`). It is nonempty if
   `C ∖ D(G)` is nonempty (`placesOver_nonempty`). Then Tau Ceti's
   `isDedekindDomain_holomorphyRing_compl`, `finiteType_holomorphyRing_compl`
   and `isFractionRing_holomorphyRing` make `Γ(U')` an affine model of `K`.
6. **(3).** `Γ(U')` is a finite `Γ(U)`-module inside the fraction field of
   `Γ(U)`. A common denominator of its generators
   (`IsLocalization.exist_integer_multiples_of_finset`) is a nonzero
   `t ∈ Γ(U)` with `t·Γ(U') ⊆ Γ(U)`.
7. **(4).** `Γ(U') / Γ(U)` is a finite `Γ(U)`-module killed by `t`. So it is
   a finite module over `Γ(U) / (t)`. That ring is a finitely generated
   `k`-algebra of Krull dimension `0`, because every nonzero prime of the
   one-dimensional domain `Γ(U)` is maximal (R3,
   `Ideal.IsPrime.isMaximal_of_trdeg_fractionRing_le_one`). So it is
   finite over `k` (`Module.finite_iff_krullDimLE_zero`). By transitivity,
   `Γ(U') / Γ(U)` is finite-dimensional over `k`. Fulton's map
   `z ↦ t z` into `Γ(U)/(t)` works too.
8. **Choosing `G`.** Let `S' = S ∪ {P₀}`, where `P₀ ≠ P` is any point of
   `C` (`C` is infinite: `zeroLocus_singleton_infinite`, `d ≠ 0` because
   `F` is irreducible). For each `s ∈ S'`, take a linear form `L_s` with
   `L_s(s) = 0 ≠ L_s(P)` (`exists_sum_C_mul_X_mem_zeroLocus_notMem_zeroLocus`,
   P8). Let `G = ∏_{s ∈ S'} L_s`. Then `G(P) ≠ 0`, so `¬ F ∣ G` because
   `F(P) = 0`. Also `P ∈ D(G)`, `D(G) ∩ S = ∅`, and `P₀ ∉ D(G)`.
9. **The local form.** For `P ∈ D(G)`, `𝒪_P` is the localization of `A_G`
   at `{a ∈ A_G | a(P) ≠ 0}`: `f / g = (f·g^{m-1} / G^e) / (g^m / G^e)`
   with `g^m / G^e` a unit at `P`. So `𝒪_P` is Japanese
   (`TauCeti.Ring.isJapanese_of_isLocalization`), and its integral closure in
   `K` is module-finite. That integral closure is
   `holomorphyRing (placesOver hF P)`, directly from Tau Ceti's theorem and
   `mem_placesOver_iff_le`. A conductor element `t ∈ 𝒪_P` (step 6) then
   gives `e : ℕ` with: if `ord_Q z ≥ e` for every `Q` over `P`, then
   `z ∈ 𝒪_P`. Take `e ≥ ord_Q t` for each of the finitely many `Q`. Then
   `z / t ∈ holomorphyRing (placesOver hF P)`, so `z = t · (z / t) ∈ 𝒪_P`.
10. **The last sentence, for every `U ⊆ C`.** We need
    `{Q | Γ(U) ⊆ 𝒪_Q} = center hF ⁻¹' U`; Tau Ceti's theorem does the rest.
    `⊇` is `Γ(U) ⊆ 𝒪_{center Q} ⊆ 𝒪_Q`. For `⊆`, let `center Q ∉ U`. We
    build `w ∈ Γ(U)` with a pole at `Q`. Let `Z` be the finite set of places
    over the multiple points of `C` that lie in `U`
    (`finite_setOf_isMultiplePoint_of_irreducible`, `placesOver_finite`).
    So `Q ∉ Z`. Let `e` be the maximum of the exponents of step 9 over
    these points. Then:
    - `u ∈ holomorphyRing Z` with `ord = e` on `Z`
      (`TauCeti.exists_holomorphyRing_forall_ord_eq`, V7);
    - `y ≠ 0` regular at every place `≠ Q`, with `y u⁻¹` also regular there
      (`TauCeti.exists_ne_zero_mem_holomorphyRing_and_mul_mem` for
      `S = {Q}ᶜ`), so `ord y ≥ e` on `Z`;
    - `x` with its only pole at `Q`
      (`TauCeti.Place.exists_ord_neg_and_forall_ne_ord_nonneg`).

    Let `w = x^N y` with `N > ord_Q y`. Then `ord_Q w < 0`, and `w` is
    regular at every place `≠ Q` with `ord ≥ e` on `Z`. Take `P' ∈ U`. If
    `P'` is simple, `𝒪_{P'}` is the valuation ring of the place at `P'`,
    which is `≠ Q` (`integers_toSubring_placeAt`). If `P'` is multiple,
    use step 9. Either way, `w ∈ 𝒪_{P'}`.

## Decisions

These answer the questions of #359.

### 1. Rings of regular functions on subsets of `C`

V6 adds **`Projective.regularFunctions hF U : Subalgebra k K`**, the
intersection `⋂_{P ∈ U} 𝒪_P`. This is Fulton's `Γ(U)`, for every set `U`.
It does not go through an affine chart and R1's `regularFunctionsOn`, for
three reasons:

- a neighbourhood `D(G)` need not lie in one chart;
- R1 needs `MaximalSpectrum` of the chart's coordinate ring, and the library
  has no bijection between it and the chart's points of `C`;
- V3 and V8 work with the projective `localSubring hF P` and places.

The name is not `regularFunctionsOn`. Inside the namespace
`PlaneCurves.Projective`, that name would be ambiguous with R1's
`PlaneCurves.regularFunctionsOn`.

### 2. Which neighbourhoods `U`

The basic open sets `D(G)` of forms `G` with `¬ F ∣ G`. They are written
`{P : C | eval P.1.rep G ≠ 0}`, with no definition: only V6 uses them, in a
few statements. Their ring is the k-subalgebra
**`Projective.awaySubalgebra hF hG hFG`** of fractions `H / Gʳ`, with
`deg H = r·m`. Its API: membership, `awaySubalgebra_le_regularFunctions`
(`A_G ⊆ Γ(D(G))`), finite type, fraction field `K` and the localization at
a point (these two for `m ≠ 0`). `Γ(D(G)) = A_G` is true, but V6 does not need it and does not prove
it ([the route](#the-route)).

### 3. How to state "`U'` is affine" (1)

In the place model, `U'` is affine when `Γ(U')` is an **affine model** of
`K` in Tau Ceti's sense: a finitely generated `k`-algebra, a Dedekind
domain, with fraction field `K`. That is three conjuncts,
`Algebra.FiniteType k Γ(U')`, `IsDedekindDomain Γ(U')` and
`IsFractionRing Γ(U') K`. Under them, Tau Ceti's
`holomorphyRingHeightOneSpectrumEquiv` is a bijection
`center hF ⁻¹' U ≃ HeightOneSpectrum Γ(U')` (`Q` goes to its centre,
`𝔭` to `Place.ofPrime 𝔭`). The valuation ring of `Place.ofPrime 𝔭` is the
localization at `𝔭`. So the points of `U'` are the maximal ideals of `Γ(U')`, with the right local rings.
That is what "`U'` is an affine open subset of `X`" means.

The other candidate from #359, `{Q | Γ(U') ⊆ 𝒪_Q} = U'`, is not the content
of (1). It holds for **every** set of places
(`TauCeti.coe_holomorphyRing_subset_integers_iff`), including `Set.univ`,
whose ring is `k`, which is not affine.

### 4. The forms of (2)–(4)

With `Γ := regularFunctions hF U`, `Γ' := holomorphyRing (center hF ⁻¹' U)`,
and `h := regularFunctions_le_holomorphyRing hF U : Γ ≤ Γ'`:

- (2) `Module.Finite Γ (integralClosure Γ K)`. With the last sentence,
  `(integralClosure Γ K).restrictScalars k = Γ'`, this says that `Γ'` is
  module-finite over `Γ`. It uses Mathlib's idiom
  (`IsJapanese.finite_integralClosure`) and needs no `Algebra Γ Γ'`
  instance.
- (3) `∃ t ∈ Γ, t ≠ 0 ∧ ∀ z ∈ Γ', t * z ∈ Γ`.
- (4) `Module.Finite k (Γ' ⧸ LinearMap.range (Subalgebra.inclusion h).toLinearMap)`:
  the cokernel of `Γ ↪ Γ'` is finite-dimensional over `k`.

### 5. The generality of the last sentence

The library proves `Γ(f⁻¹(U))` = integral closure of `Γ(U)` for **every
subset** `U ⊆ C` (step 10 of [the route](#the-route)). That includes every
open set (`∅` and the cofinite sets), so it is more general than the atlas.
It needs no entry in `ERRATA.md` and no departure. In particular,
`U = Set.univ` gives `regularFunctions hF Set.univ = ⊥`: a function regular
at every point of `C` is constant.

### 6. The local form that V8 uses

For every `P : C`, with `𝒪_P := (localSubring hF P).toSubring`:

- `integralClosure_localSubring` :
  `(integralClosure 𝒪_P K).toSubring = (holomorphyRing (placesOver hF P)).toSubring`;
- `finite_integralClosure_localSubring` :
  `Module.Finite 𝒪_P (integralClosure 𝒪_P K)`;
- `exists_ne_zero_mul_mem_localSubring` :
  `∃ t ∈ 𝒪_P, t ≠ 0 ∧ ∀ z ∈ holomorphyRing (placesOver hF P), t * z ∈ 𝒪_P`;
- `exists_forall_le_addValuation_mem_localSubring` :
  `∃ e : ℕ, ∀ z : K, (∀ Q ∈ placesOver hF P, (e : WithTop ℤ) ≤ Q.addValuation z) → z ∈ 𝒪_P`.

V8's library route ("`Ã/A` has finite length, so `ℓ(A/gA) = ℓ(Ã/gÃ)`")
starts from the first three. `Ã/A` embeds in `𝒪_P/(t)` by `z ↦ t z`. Write
`t = G / H` with `H(P) ≠ 0`, so `t` is associated to `G / Lᵐ`. Then
`𝒪_P/(t)` is `𝒪_P(ℙ²)/(F_*, G_*)` (Q5's `quotientSpanPairEquiv`). Its
length is `I(P, F ∩ G) < ∞`, since `¬ F ∣ G`. The finiteness of `δ_P` belongs
to V8 and is not part of V6.

## Definitions and their API

### The conductor (`RingTheory/Conductor.lean`)

This needs no definition. It is a lemma about Tau Ceti's `TauCeti.Algebra.conductor`,
in that namespace so that it can move to `TauCeti/RingTheory/Conductor.lean`:

```lean
theorem TauCeti.Algebra.exists_mem_conductor_of_isLocalization
    {A B L : Type*} [CommRing A] [CommRing B] [CommRing L] [Algebra A B] [Algebra A L]
    [Algebra B L] [IsScalarTower A B L] (M : Submonoid A) [IsLocalization M L]
    [Module.Finite A B] (hB : Function.Injective (algebraMap B L)) :
    ∃ a ∈ M, a ∈ conductor A B
```

Proof: generators of `B`, common denominator by
`IsLocalization.exist_integer_multiples_of_finset`, then `mem_conductor_iff`
and `Submodule.span_induction`. About 40 lines.

### Quotients of a curve's ring (`KrullDimension/TrdegOne.lean`)

```lean
theorem Module.finite_quotient_span_singleton_of_trdeg_le_one
    [Algebra.FiniteType k R] (h : Algebra.trdeg k R ≤ 1) {t : R} (ht : t ≠ 0) :
    Module.Finite k (R ⧸ Ideal.span {t})
```

`R` is a `k`-domain, as in the rest of the file. Proof: `R ⧸ (t)` has
dimension `0` (`Ideal.IsPrime.isMaximal_of_trdeg_fractionRing_le_one`, with
`Ideal.krullDimLE_zero_quotient_iff_forall_minimalPrimes_isMaximal`), and it
is of finite type, so it is finite (`Module.finite_iff_krullDimLE_zero`).
About 30 lines.

### `regularFunctions` (`Projective/RegularFunctions.lean`)

```lean
/-- The ring `Γ(U) = ⋂_{P ∈ U} 𝒪_P(C)` of rational functions on `C` regular at every point
of `U`. -/
noncomputable def regularFunctions (U : Set C) : Subalgebra k (functionField hF) where
  carrier := {z | ∀ P ∈ U, z ∈ (localSubring hF P).toSubring}
  ...
```

API:
- `mem_regularFunctions_iff` (`Iff.rfl`, `@[simp]`);
- `coe_regularFunctions` : `(regularFunctions hF U : Set K) = ⋂ P ∈ U, ↑(localSubring hF P).toSubring`;
- `antitone_regularFunctions`, `regularFunctions_anti` (as R1's names);
- `regularFunctions_empty` (`= ⊤`, `@[simp]`);
- `regularFunctions_union` (`= Γ(U) ⊓ Γ(V)`);
- `regularFunctions_singleton` : `(regularFunctions hF {P}).toSubring = (localSubring hF P).toSubring`;
- `regularFunctions_le_holomorphyRing` :
  `regularFunctions hF U ≤ holomorphyRing (center hF ⁻¹' U)` (from
  `localSubring_center_le`).

`regularFunctions_univ` (`= ⊥`) is proved in `Normalization.lean`, since it
uses the last sentence. V3's `IsNonsingular.iInter_localSubring_eq_holomorphyRing`
is its nonsingular case, stated with `⋂`. It can be restated with
`regularFunctions` in a refactor of its own; V6 does not need that.

### `awaySubalgebra` (`Projective/RegularFunctions.lean`)

```lean
variable {m : ℕ} {G : MvPolynomial (Fin 3) k}

/-- The ring `A_G` of fractions `H / Gʳ`, `H` a form of degree `r·m`, for a form `G` of degree
`m` not divisible by `F`: the ring of the basic open set `D(G)`. -/
noncomputable def awaySubalgebra (hG : G.IsHomogeneous m) (hFG : ¬ F ∣ G) :
    Subalgebra k (functionField hF)
```

The carrier is `{z | ∃ r H (hH : H.IsHomogeneous (r * m)), z = functionField.mk hH (hG.pow r) _}`.
The proof that `Gʳ ∉ (F)` comes from `hFG` and `Prime F`. API:
- `mem_awaySubalgebra_iff`, `mk_mem_awaySubalgebra`;
- `awaySubalgebra_le_regularFunctions` :
  `awaySubalgebra hF hG hFG ≤ regularFunctions hF {P | eval P.1.rep G ≠ 0}`;
- `awaySubalgebra_eq_adjoin` :
  `= Algebra.adjoin k {z | ∃ M, M is a monomial of degree m ∧ z = M / G}`, and
  the instance-style lemma `finiteType_awaySubalgebra`;
- `isFractionRing_awaySubalgebra` : for `hm : m ≠ 0`,
  `IsFractionRing (awaySubalgebra hF hG hFG) K`;
- `isLocalization_localSubring_awaySubalgebra` : for `hm : m ≠ 0` and
  `eval P.1.rep G ≠ 0`,
  `𝒪_P` is the localization of `A_G` at the prime `{a | a(P) = 0}`. Use
  Mathlib's `Localization.subalgebra.ofField` (as R1 does) and the identity
  `f / g = (f·g^{m-1} / G^e) / (g^m / G^e)`. State the prime as the
  `comap` of `IsLocalRing.maximalIdeal 𝒪_P` under the inclusion
  `A_G → 𝒪_P`. The inclusion is `Subring.inclusion` of
  `awaySubalgebra_le_regularFunctions` composed with membership at `P`.

These two need `m ≠ 0`. For `m = 0`, `G` is a nonzero constant, `D(G) = C`
and `A_G = k`. Its fraction field is `k`, not `K`, which is transcendental
over `k`, and `𝒪_P` is not a localization of `k`. The rest of the API holds
for every `m`.

## Main results

All in `NonsingularModel/Normalization.lean`, namespace `PlaneCurves.Projective`.

### Integral closure of `A_G`

- `setOf_awaySubalgebra_subset_integers` :
  `{Q | (awaySubalgebra hF hG hFG : Set K) ⊆ Q.integers} = center hF ⁻¹' {P | eval P.1.rep G ≠ 0}`
  (step 2).
- `restrictScalars_integralClosure_awaySubalgebra` :
  `(integralClosure A_G K).restrictScalars k = holomorphyRing (center hF ⁻¹' D(G))`.
- `finite_integralClosure_awaySubalgebra` : `Module.Finite A_G (integralClosure A_G K)`.

### The local form (Decision 6)

`integralClosure_localSubring`, `finite_integralClosure_localSubring`,
`exists_ne_zero_mul_mem_localSubring`,
`exists_forall_le_addValuation_mem_localSubring`, as stated
[above](#6-the-local-form-that-v8-uses).

### The last sentence (Problem 7.20 (c))

```lean
theorem setOf_regularFunctions_subset_integers (U : Set C) :
    {Q | (regularFunctions hF U : Set K) ⊆ Q.integers} = center hF ⁻¹' U

theorem restrictScalars_integralClosure_regularFunctions (U : Set C) :
    (integralClosure (regularFunctions hF U) K).restrictScalars k =
      holomorphyRing (center hF ⁻¹' U)

@[simp] theorem regularFunctions_univ : regularFunctions hF Set.univ = ⊥
```

`regularFunctions_univ` follows from the second with `holomorphyRing_univ`
and `IsAlgClosed` (`algebraicClosure k K = ⊥`). The second is
`restrictScalars_integralClosure_eq_holomorphyRing` with the first.

### The neighbourhood

```lean
theorem exists_basicOpen_normalization (P : C) {S : Set C} (hS : S.Finite) (hPS : P ∉ S) :
    ∃ (m : ℕ) (G : MvPolynomial (Fin 3) k) (hG : G.IsHomogeneous m) (hFG : ¬ F ∣ G),
      eval P.1.rep G ≠ 0 ∧ (∀ s ∈ S, eval s.1.rep G = 0) ∧
      ∃ Q : C, eval Q.1.rep G = 0
```

This is step 8. The rest of the milestone is proved for any such `G`, in
lemmas whose hypotheses are `hG`, `hFG` and the existence of a zero of `G`
on `C`. That zero forces `m ≠ 0`, since a form of degree `0` not divisible
by `F` is a nonzero constant. The lemmas derive `hm` from it, to apply
`isFractionRing_awaySubalgebra`:

- `finiteType_regularFunctions_basicOpen`,

### The milestone

```lean
/-- **Finiteness of the normalization of a plane curve near a point.** Let `C : F = 0` be an
irreducible projective plane curve over an algebraically closed field, with nonsingular model
the places of `k(C)` and their centres. For `P ∈ C` and a finite `S ⊆ C` with `P ∉ S` there is
a basic open set `U = D(G) ∋ P` with `U ∩ S = ∅`, whose ring `Γ(U)` is a finitely generated
`k`-algebra with fraction field `k(C)`, such that (1) the ring `Γ(U')` of the places `U'` over
`U` is an affine model of `k(C)`, (2) the integral closure of `Γ(U)` is a finite `Γ(U)`-module,
(3) `t Γ(U') ⊆ Γ(U)` for some `t ≠ 0` in `Γ(U)`, and (4) `Γ(U') / Γ(U)` is finite-dimensional
over `k`. Moreover, for every `U ⊆ C`, `Γ(U')` is the integral closure of `Γ(U)` in `k(C)`.

Milestone: *Finiteness of the normalization of a plane curve near a point*. -/
theorem finite_normalization_spec (P : C) {S : Set C} (hS : S.Finite) (hPS : P ∉ S) :
    (∃ U : Set C,
      (∃ (m : ℕ) (G : MvPolynomial (Fin 3) k), G.IsHomogeneous m ∧ ¬ F ∣ G ∧
        U = {P' | eval P'.1.rep G ≠ 0}) ∧
      P ∈ U ∧ Disjoint U S ∧
      Algebra.FiniteType k (regularFunctions hF U) ∧
      IsFractionRing (regularFunctions hF U) (functionField hF) ∧
      -- (1)
      Algebra.FiniteType k (holomorphyRing (center hF ⁻¹' U)) ∧
      IsDedekindDomain (holomorphyRing (center hF ⁻¹' U)) ∧
      IsFractionRing (holomorphyRing (center hF ⁻¹' U)) (functionField hF) ∧
      -- (2)
      Module.Finite (regularFunctions hF U)
        (integralClosure (regularFunctions hF U) (functionField hF)) ∧
      -- (3)
      (∃ t ∈ regularFunctions hF U, t ≠ 0 ∧
        ∀ z ∈ holomorphyRing (center hF ⁻¹' U), t * z ∈ regularFunctions hF U) ∧
      -- (4)
      Module.Finite k (holomorphyRing (center hF ⁻¹' U) ⧸
        LinearMap.range (Subalgebra.inclusion (regularFunctions_le_holomorphyRing hF U)).toLinearMap)) ∧
    ∀ U : Set C, (integralClosure (regularFunctions hF U) (functionField hF)).restrictScalars k =
      holomorphyRing (center hF ⁻¹' U)
```

The statement has the atlas's hypotheses: `k` algebraically closed, `C`
irreducible, `P ∈ C`, `S` finite with `P ∉ S`. Its last conjunct holds for
every subset `U`, not only for open ones.

## Notes

- **No errata.** The atlas's statement holds as written in every
  characteristic. V6 proves it with the last sentence for every subset `U`,
  which is more general. It adds nothing to `ERRATA.md`.
- **"Affine open neighbourhood `U`".** The library has no abstract affine
  varieties. `U` is a basic open set `D(G) = C ∖ V(G)` of a form `G` with
  `¬ F ∣ G`, the standard affine open sets of `C`. The milestone records
  that `Γ(U)` is a finitely generated `k`-algebra with fraction field `k(C)`. It does not
  prove that the maximal ideals of `Γ(U)` are the points of `U`: none of (1)–(4), V8 or the later
  parts use it. A later part that needs it can prove it by lying over, from
  `Γ(U')` integral over `Γ(U)` and (1).
- **Why the sandwich.** Proving `Γ(D(G)) = A_G` needs a projective
  Nullstellensatz for the ideal of denominators. The sandwich `A_G ⊆ Γ(U) ⊆ Γ(U')`
  gives everything the milestone states without it.
- **The book's route** (quadratic transformations, Problem 7.13) needs
  characteristic `0` and is not used.
- **For V8.** V8 uses the four lemmas of Decision 6 and `placesOver_finite`.
  The δ-invariant `dim_k Ã/𝒪_P` is not defined. V8 proves that it is finite
  if it needs it, by the argument of Decision 6.
